# スライド型録 — PowerPoint Template Gallery

Canvaのプレゼンテンプレート一覧のように、テンプレートを選んで色・フォント・表紙の文字を整え、**編集できる .pptx** としてダウンロードできるブラウザ完結ツールです。

## 特長
- 40テンプレート（12デザイン × 16カラーの組み合わせ）
- 用途（企画書／事業報告／ピッチ資料／研修・教育／マーケティング／会社説明・採用／セミナー・講演／プロジェクト計画）、テイスト、カラーで絞り込み・検索
- 1テンプレートにつき11レイアウト：表紙・目次・中扉・要点・テキスト＋画像・数値ハイライト・タイムライン・3カラム比較・グラフ・表・結び
- カラー16種・フォント4種（游ゴシック／メイリオ／BIZ UDゴシック／明朝×ゴシック）に切り替え可能
- 収録するスライドを選んで書き出し。図形・テキスト・グラフ（ネイティブ）・表はすべてPowerPointで編集可能
- お気に入り（ブラウザに保存）、`#t12` のようなURLで特定テンプレートを直接開ける
- スマホ対応。データは外部に送信しません

## 使い方（GitHub Pages）
1. このリポジトリに `index.html` を置く
2. Settings → Pages → Branch: `main` / `(root)` を選んで保存
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

## カスタマイズ
`index.html` 内の定数を編集します。
- `PALETTES` … カラーパレットの追加
- `STYLES` … デザイン（装飾と文字配置）の追加
- `CONTENT` … 用途別のサンプル文面
- `TEMPLATES` … `[名前, 用途, デザイン, カラー, フォント, テイスト]` の1行で1テンプレート追加

## 使用ライブラリ
- [PptxGenJS](https://github.com/gitbrent/PptxGenJS) 3.12.0（CDN読み込み）
